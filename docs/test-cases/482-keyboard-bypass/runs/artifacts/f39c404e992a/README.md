# Historical verification logs

[Download the complete sanitized logs](verification-logs.zip). [Manifest and SHA-256 checksums](manifest.json).

These are the original execution artifacts associated with application commit `f39c404e992a88093a07407054006c4ae14d9a3d`, retained from the original PR author’s local review directory. They are historical evidence and do not establish results for later review corrections.

The archive includes the full source gate, script suite, final browser rerun, offline API, MCP/framing and in-app results, plus the original failing keyboard and native fallback runs, earlier intermittent browser runs, the default embedding timeout and independent static verdicts. Test results and failure details are preserved. Local user/worktree paths and recognizable credential fields were sanitized; the archive contains no databases or private credential files.

The separate follow-up record states which checks were rerun for later changes and which remain unverified.
