## Failures investigated and limits

- Initial storage tests incorrectly expected a semantic event's nullable `TaskId` rather
  than its actual `EntityType`/`EntityId` contract. Corrected the assertions; no audit
  implementation change was needed for that failure.
- Source inspection found a remaining `Trim()` in the card save handler. A real-handler
  regression now catches a whitespace-only edit that the old implementation skipped.
- Playwright `fill`/`insertText` attempts on large multiline values timed out and produced
  a SignalR client timeout. Direct DOM input isolated the save path; the final complete
  scenario uses real clipboard paste and passes. The failed attempts are retained in logs;
  they are not presented as passing evidence or actual human feedback.
- The attempted `ConfigureConnection` API from the current docs was absent in the installed
  framework. The final build uses the supported endpoint-metadata convention for the inbound
  buffer. See [Blazor hub configuration](https://learn.microsoft.com/en-us/aspnet/core/blazor/fundamentals/signalr?view=aspnetcore-10.0#blazor-hub-options)
  and [SignalR buffer settings](https://learn.microsoft.com/en-us/aspnet/core/signalr/configuration?view=aspnetcore-10.0#advanced-http-configuration-options).
- The transport fixture initially used unsupported native `create_feature`; switched fixture
  creation to the existing stdio tool. The subsequent exact comment assertion exposed the
  wrapper's real whitespace trim; fixed that path and reran the actual clients successfully.
- The normal-browser helper initially used `URL` outside the browser sandbox; corrected the
  helper to inspect `location.origin` inside `page.evaluate`, then the whole check passed.
- Mermaid initially interpreted a semicolon in a sequence label as a statement separator.
  Reworded the label and rendered the corrected diagram successfully.
- Optional static source/test pairing could not run because `tree-sitter-language-pack` was
  absent. No pairing/coverage result is claimed. The independently reviewed importer cases,
  real-handler/service tests and actual transport/browser evidence are recorded separately
  in `.git/testagent/full-content-20260907/` and this guide.

The 4 MiB message limit and 8 MiB inbound buffer are finite transport bounds, not storage
clipping rules. Browser textareas normalize source CRLF to LF while editing; source imports
through API/MCP preserve CRLF exactly. Ordinary task PUT has no atomic optimistic token;
recovery re-reads immediately before writing but does not claim an atomic compare-and-swap.
Future source edits to already complete imports remain #495. Human usability/acceptance is
pending; this run does not complete U-10 or implement proposed outline stages U-15–U-17.
